# Roadmap v1.3.0 — React Migration + UI Redesign

> **Status:** Planned  
> **Target branch:** `frontend` (main) + `backend` (template cleanup)  
> **Previous version:** v1.2.0  
> **Dependencies:** None

---

## Goal

Fully migrate the frontend from Jinja2 + vanilla JS to React + Tabler UI.
FastAPI becomes a pure REST API. The user gets a modern dashboard experience
with a financial summary Home and a User Profile page.

---

## Scope

### Deprecations
- Remove entire `backend/app/templates/` folder
- Remove HTML serving from FastAPI
- Remove Jinja2 dependency from `requirements.txt`
- Remove files in `frontend/web/` (vanilla JS, manual CSS)

### Backend — minimal changes
- [ ] Ensure all endpoints return pure JSON (no template rendering)
- [ ] Enable CORS correctly in `main.py` for the frontend domain
- [ ] Review and clean up routes that depended on Jinja2
- [ ] Update `structure.md` with the new frontend architecture

### Frontend — React + Tabler
- [ ] Initialize React project with Vite inside `frontend/`
- [ ] Install base dependencies: `@tabler/react`, `@tabler/icons-react`, `react-router-dom`, `axios`
- [ ] Set up centralized HTTP client (`src/api/client.js`) with JWT interceptors
- [ ] Implement `access_token` and `refresh_token` handling via localStorage
- [ ] Configure protected routes with React Router

---

## Pages

### `/` — Home (Dashboard)
- Total balance card for the current month
- Income vs expenses card (current vs previous month)
- Last 5 transactions
- Expenses by category chart (bar or donut)
- Quick access button for "New Transaction"

### `/profile` — User Profile
- User data: name, email, avatar
- Edit name and password
- Account creation date
- Sign out button

### `/transactions` — Transaction List (migration)
- Table with filters: date, type, category
- Pagination
- Export button (backend already supports it)

### `/login` and `/register` — Auth (migration)
- Clean Tabler forms
- Inline error handling

## Proposed Frontend Structure

```
frontend/
├── src/
│   ├── api/           # HTTP client + resource-specific calls
│   ├── components/    # Reusable components (Tabler wrappers)

│   │   ├── Profile/
```

## Technical Notes

- Tabler React uses Bootstrap 5 internally — do not mix with other CSS frameworks.
- JWT token must be sent in the `Authorization: Bearer <token>` header on every request.
- For Railway deploy: the React `dist/` can be served as a static site or via Nginx.
- Consider TanStack Query if async state management becomes complex.
